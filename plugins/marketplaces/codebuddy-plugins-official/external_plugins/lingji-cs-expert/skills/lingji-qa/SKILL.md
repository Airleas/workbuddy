# 灵光记 FAQ 检索技能

本技能提供**离线、零依赖**的 FAQ 检索能力。知识库已随插件打包在 `data/qa/` 目录（12 个分组 md，共 82 条 QA），无需任何外部服务或网络连接。

## 使用方式

在需要查标准答案时，运行检索脚本：

```bash
python3 "<插件根目录>/skills/lingji-qa/scripts/retrieve.py" "客户的原话整段贴这里" --top 3
```

- 插件根目录可用环境变量 `${CODEBUDDY_PLUGIN_ROOT}` 获取；若不可用，则从本 SKILL.md 所在位置向上三级即为插件根。
- `--top N` 控制返回几条候选（默认 3）。
- 也可显式指定数据目录：`--data-dir /path/to/qa`。

## 输出格式

脚本输出 JSON：

```json
{
  "matches": [
    {"qid": "Q5.6", "question": "设备连接不上怎么办呀", "answer": "（标准答案全文）", "score": 0.83}
  ],
  "total": 82,
  "need_human": []
}
```

- `matches` 为空 = 知识库无匹配，应如实告知并建议转人工。
- `need_human` 非空 = 客户原话涉及退款/投诉/注销/隐私/数据恢复/订单核验等必须人工处理的主题，机器人不得代答。

## 使用要点

1. **整段传入**：把客户原话（含口语、情绪、多问题）整段作为查询，不要先拆解或改写。
2. **靠分数更要靠判断**：返回的 `score` 只是字面二元组覆盖率，高分候选也可能答非所问；需结合语义判断是否真正命中。
3. **多问题分别匹配**：客户一次问多个点时，可多次调用、逐条匹配。
4. **置信度低就转人工**：当 `matches` 为空或候选都不贴切时，明确说"知识库暂无标准答案，建议转人工"，并附通用安抚 + 转人工指引，绝不编造。
