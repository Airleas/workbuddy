# 灵光记客服 FAQ：兑换码与活动

> 来源：原《灵光记-电商客服FAQ（亲民版）》第 3 章。

## 3. 兑换码与活动

### Q3.1 什么是兑换码呀？

亲，兑换码是亲通过**购买电商硬件捆绑套餐**或者**参加官方运营活动**拿到的专属凭证哦，可以用来兑换年付高级会员或年付精英会员权益呢~

- 格式：10-12 位字母+数字（已经帮亲去掉容易看混的 0/O、1/I 啦），可能有前缀比如 `SPK-xxxxxx`
- 兑换后会根据亲当前的会员等级**马上生效、同级叠加或者拒绝兑换**，会员中心不展示未来的会员记录哈
- 硬件捆绑的会员也是以兑换码形式发放的，不会在 App 前台单独显示成一类权益来源哦

### Q3.2 怎么兑换呀？

亲，在 App 里这样操作就好啦：
「我的页面」→「会员中心」→「兑换码」→ 输入兑换码 → 确认兑换

很简单哒~

### Q3.3 兑换码与订单、设备怎么关联的呀？

亲，背后有个**核心三要素绑定链路**，帮您解释一下哈：

- 亲在电商平台下单的时候，系统会把**订单号 + SN 码**推送给兑换码后台
- 后台会自动抓取还没用过的兑换码跟订单绑定
- 仓库发货的时候扫描设备外箱 SN 码，这样全链路就绑定好啦~

### Q3.4 亲要退货的话，兑换码怎么处理呀？

亲，这个分情况处理的哈：

| 场景 | 处理方式 |
|---|---|
| **兑换码还没用** | 客服后台把这个码变成「已作废」，正常退货退款就行啦~ |
| **兑换码已经用了** | 仓库扫码 SN 码 → 系统追溯订单和兑换码 → **只回收这个兑换码对应的权益** → 亲会收到系统通知的 |

### Q3.5 兑换码的有效期是多久呀？

亲，兑换码有**独立有效期**的哈（后台配置的，跟套餐本身的积分没关系），亲一定要在有效期内激活使用哦，过期就作废啦，记得早点兑换呢~

### Q3.6 兑换码发错了或者亲反馈失效了怎么办？

亲别急，客服可以在后台帮亲做**「作废并重新生成」**操作，系统会自动把旧码作废，然后关联一个新码给这个订单~会帮亲处理好的！

### Q3.7 兑换码可以跨平台使用吗？

可以的亲！兑换码生成的会员权益是跟灵光记账号绑定的，**iOS 和 Android 都能用**，放心哈~

### Q3.8 iOS 用户兑换会员码后，App Store 订阅会自动取消吗？

亲，**不会的哦**。兑换码只影响灵光记账号里的会员权益，不会自动取消、暂停、延长或修改 App Store 的订阅呢。

如果亲当前已经有 iOS 自动续费订阅，兑换码生效后还是有可能会继续被 Apple 扣费的哈，亲记得自己去检查一下订阅状态哦~

### Q3.9 兑换码在不同会员状态下怎么生效呀？

亲，兑换码兑换成功后，会员中心只展示亲当前可用的会员等级和更新后的到期时间；要是兑换失败，也会告诉亲具体原因的~

常见情况给亲列一下：

| 当前会员 | 兑换会员码 | 处理方式 |
|---|---|---|
| 标准会员 | 高级/精英码 | 马上生效！ |
| 高级会员 | 高级码 | 叠加到当前高级会员有效期后面，只显示延长后的到期时间~ |
| 高级会员 | 精英码 | 立刻升级成精英会员；原来的高级会员方案直接替代，不恢复哦 |
| 精英会员 | 高级码 | 不支持兑换，权益不变呢 |
| 精英会员 | 精英码 | 叠加到当前精英会员有效期后面，只显示延长后的到期时间~ |
