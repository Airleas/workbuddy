# 灵光记客服 FAQ：APP 功能详解

> 来源：原《灵光记-电商客服FAQ（亲民版）》第 7 章。

## 7. APP 功能详解

### Q7.1 录音支持哪些方式呀？

亲，我们有三种录音方式呢：

| 方式 | 说明 | 适用场景 |
|---|---|---|
| **手机录音** | 用手机麦克风录，支持暂停/继续/停止 | 临时录音、快速记录 |
| **设备录音** | 灵光闪记卡录制，连接手机后同步到 App | 会议、课堂、采访 |
| **双轨录音** | 手机+设备同时录，互不影响 | 重要场合双重保障！ |

### Q7.1.1 单次录音和转写有上限吗？

有的亲，单次录音/转写的上限统一是 **300 分钟（5 小时）**，所有会员都一样哈~

| 项目 | 上限 |
|---|---|
| 手机录音单次上限 | 300分钟（5小时） |
| 设备录音单次上限 | 300分钟（5小时） |
| 导入音频单次转写上限 | 300分钟（5小时） |
| 单次转写扣费 | 按实际音频时长扣积分，1积分=1分钟 |

### Q7.2 录音后 AI 做什么呀？

亲，录音完成后，灵光记会自动（或者亲手动操作）帮亲做这些事：

- **AI 转写**：把录音转成文字，还能区分说话人、带时间戳，超方便！
- **AI 总结**：按会议、课堂、访谈、通话等模板生成整整齐齐的结构化笔记~
- **待办提取**：从录音内容里识别任务、负责人和截止时间，自动同步到待办列表！
- **思维导图**：把长内容整理成层级结构，方便复盘和分享~
- **LynClaw 追问**：还可以继续围绕当前文件、标签或者全部文件提问哦
- **多端协同**：手机/平板通过灵光记 App 查看，电脑端可以通过 OpenClaw 等 AI Agent 接入方式处理，具体可用范围以当前版本为准哈~

### Q7.3 AI 转写准确度怎么样？

亲，转写准确度受这几个因素影响哦：

- **录音环境**：安静环境下准确度最高！所以建议亲尽量在安静的地方录音~
- **音频语言**：支持范围以 App 内实际可选语言为准；目前宣传是 120+ 种语言、30+ 种方言、200+ 行业术语
- **拾音质量**：4 MIC + 1 骨传导传感器、360° 拾音和智能降噪；实际效果会受距离、环境噪声、说话音量和遮挡情况影响哈
- **行业术语**：亲可以在设置里选行业词库，提升专业术语的识别率~
- **说话人数**：支持多人对话的说话人标注呢！

### Q7.4 转写额度用完了怎么办呀？

亲，不同会员类型额度用完后处理方式不一样哦：

| 会员类型 | 额度用尽后 |
|---|---|
| **普通用户**（没绑定设备） | 会弹出引导页，提示亲购买或绑定灵光闪记卡，跳转到购买渠道或设备绑定引导页；绑定设备后升级为标准会员就有 500 积分/月啦~ |
| **标准会员 / 高级会员** | 可以买**充电包**增加额度，或者升级到更高级别会员哦~ |
| **精英会员** | 无限转写，不存在的！随便用~ |

（普通用户相关内容后续版本会开放哈）

### Q7.5 AI 转写怎么收费呀？

亲，转写按**积分**扣费：1 积分 = 1 分钟转写时长。不足 1 分钟的按 1 积分扣哦。单次录音/转写上限是 300 分钟（5 小时）。

不同会员等级的月度额度亲可以看 Q4.2 哈~

### Q7.6 转写和笔记结果可以导出哪些格式呀？

亲，支持导出的格式还挺全的：

| 导出类型 | 支持格式 |
|---|---|
| 音频 | MP3 / WAV |
| 转写文字 | TXT / SRT / PDF |
| 总结 | TXT / MarkDown / PDF |
| 思维导图 | JPEG / MarkDown |

导出的时候还可以设置**包含时间戳**、**区分说话人**呢~

### Q7.7 AI 助手（LynClaw）是什么呀？

亲，LynClaw 是灵光记内置的智能 AI 对话助手，超实用的：

- 在任何页面都能**从下往上滑唤出来**
- **三种提问范围**：全部文件 / 特定标签文件 / 单文件，随亲选~
- **两种输入方式**：打字输入 / 语音输入（上限1分钟）
- **智能引用**：@ 可以提及文件、# 可以引用标签（最多3个）
- **联网搜索**：可以在设置里开关（默认是开着的）
- **对话管理**：历史对话可以重命名、置顶、删除

### Q7.8 待办事项怎么用呀？

亲，功能很贴心的哈：

- 录音里的待办事项会**自动提取**并同步到待办列表（还会自动去重哦）
- 按截止时间分成 5 类：**本周 / 本月 / 超过一个月 / 已过期 / 没有日期**
- 支持设定**优先级**：高（红）/ 中（黄）/ 低（蓝）/ 没设置
- **今天有没处理的待办**时，首页顶部会有滚动横幅提醒，亲可以在【我的】页面关掉~
- 待办到期前一天 10 点会推送提醒（当前版本还没开放哈）
- 勾选完成 → 进「已完成待办」，可以恢复或永久删除

### Q7.9 云同步要收费吗？

亲，**免费提供给所有用户的！** 可以在设置里开关，还能选「仅在 Wi-Fi 下自动同步」，帮亲省流量~

### Q7.10 App 支持哪些语言呀？

亲，目前支持这些（后续还会更新更多语言哈）：

| 选项 | 说明 |
|---|---|
| **Auto（跟随系统）** | 跟着设备系统语言走，唯一会自动变的选项~ |
| 简体中文 | 界面显示简体中文 |
| 繁体中文 | 界面显示繁体中文 |
| English | 界面显示英文 |

### Q7.11 UI 文本有哪些长度限制呀？

亲，这个给亲参考一下哈：

| 位置 | 限制 |
|---|---|
| 标签名称 | 1-10字符（超6字符会用省略号） |
| 硬件名称 | 1-15字符 |
| 昵称 | 1-20字符（超12字符会用省略号） |
| 音频文件名 | 1-100字符（超两行用省略号） |
| 待办文本 | 1-100字符 |
| 说话人名称 | 1-12字符 |
| 踩的原因 | 10-120字符 |
| 举报内容 | 10-500字符 |
| AI 对话 | 1-1000字符（超8行可滑动） |
| 电话号码 | 11位以内（不含区号） |
| 验证码 | 4位 |

### Q7.12 录音文件可以从手机导入吗？

可以的亲！App 支持直接调用系统文件入口，导入手机里已有的音频文件（MP3 / WAV / M4A 等格式都行）。

导入音频转写所有会员类型都能用，单次导入/转写上限是 **300 分钟（5 小时）**哦~
